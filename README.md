# calebwarzocha.dev

Personal site built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

```bash
git clone --recurse-submodules <repo-url>
hugo server -D        # local preview at http://localhost:1313, including drafts
hugo new writeups/<ctf-name>/<challenge>/index.md
```
